Data logs

Every number the site has saved, hour by hour: actual demand, the IESO's official forecast, and each model's prediction, with a link to the official IESO file each IESO number came from, so you can check any of them yourself.

How to read a row

Hour is Toronto time, labelled by when the hour starts ("14:00" = 2:00 to 3:00 pm). The IESO labels the same hour by its date and "hour ending" in Eastern Standard Time all year (EST, no daylight saving), shown under each hour: in winter "14:00" Toronto is hour ending 15; in summer (EDT) it is hour ending 14. Use that date and hour ending when looking a number up in an IESO file.

Actual: the source says which IESO file it came from. yearly file = the official hourly file (IESO adds each day about a day later). 5-min report = the average of the 12 five-minute readings in that hour's own report, used until the yearly file catches up (the two agree to within about 1 MW).

IESO forecast: the value saved from the IESO's Adequacy report, with the exact file version and the time it was saved. Model columns: each model's saved prediction; the small number is its miss (prediction minus actual: red = too high, blue = too low). Saved is when the predictions were made, in Toronto time. Timing says whether every prediction in the row was made live (on time) or some were calculated later from past data (after the fact, e.g. when an update didn't run).

At the IESO's time: for each hour, the time the IESO first published the forecast number the site scored (the earliest of an unbroken run of report versions with that same value; IESO republishes every 30 minutes, often without changing a given hour), and each model's newest prediction made at or before that moment, with where it came from (the hourly 7-day run, or the next-hour prediction if the IESO published within the last hour). Hours before 21 November 2026 were rebuilt from the site's own commit history and the IESO's archived report versions (tools/backfill_ieso_times.py).

Rows saved before 20 November 2026 don't have save times or IESO file versions. For those, the link goes to the day's latest Adequacy file, which may be a newer version than the one the site read; the directory listing shows every version with its publication time.

Official sources

  • Hourly demand, official: reports-public.ieso.ca/public/Demand/, file PUB_Demand_YYYY.csv (one per year). Find the row whose Date and Hour (hour ending, EST) match, and read the Ontario Demand column.
  • Five-minute readings, one file per hour: reports-public.ieso.ca/public/RealtimeTotals/, file PUB_RealtimeTotals_YYYYMMDDHH.xml (EST date + hour ending). Average the 12 EnergyMW values whose MarketQuantity is ONTARIO DEMAND. The IESO keeps these for about a month. PUB_RealtimeTotals.xml (no date) is the hour in progress, used for "this hour so far".
  • The IESO's forecast: reports-public.ieso.ca/public/Adequacy3/, the Adequacy report, one file per delivery day (PUB_Adequacy3_YYYYMMDD.xml). The IESO republishes it many times; each version stays available as ..._vN.xml, which is what each row links to. Read DocBody › ForecastDemand › OntarioDemand › ForecastOntDemand › Demand, the EnergyMW for the matching DeliveryHour (hour ending, EST). Opening a file in a browser shows it as a formatted report.
  • The IESO's own charts: ieso.ca/power-data. Its "Ontario Demand" chart shows Hourly (actual) and Projected Hourly (forecast) for the last few days, for a quick visual check. Note that its headline "Ontario Demand at H:00 EST" number can be one hour older than the label says.
  • This site's own record: every update is saved as a commit on GitHub, so the history of docs/demand_log.js shows exactly when each number first appeared and that predictions were never changed afterwards.
